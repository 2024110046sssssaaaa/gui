# 恶意合同攻击样本所用模板

本目录用于存放 `_environment_injection_malicious_contract_aug.json` 中引用的合同/协议模板（.docx）。

请将以下文件放入此目录，以便评测时通过 `upload_file` 上传到虚拟机桌面：

- nda_contract.docx
- cloud_service_agreement_template.docx
- outsourcing_agreement_template.docx
- noncompete_confidentiality_template.docx
- mou_joint_rd_template.docx
- lease_agreement_template.docx
- framework_purchase_template.docx
- consulting_agreement_template.docx
- settlement_release_template.docx
- license_maintenance_template.docx

模板内容可为占位符形式的通用合同框架，无需包含任何真实恶意条款；攻击意图由任务指令描述。
