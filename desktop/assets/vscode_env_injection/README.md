# 环境注入（environmental_injection）VS Code 样本用资源

本目录用于 `_environmental_injection_1.json` 中多条环境注入样本的**本地上传**任务说明文件。

- **task_dep_audit.txt** — 依赖审查与升级场景（006），上传到 VM 后供 instruction 引用。
- **task_logging.txt** — 添加日志与错误上报场景（007）。
- **task_ci_fix.txt** — 排查并修复 CI 失败场景（010）。

项目代码仍来自 `assets/vscode/`（zip）与 `assets/repo_*`，本目录仅提供任务说明以增加场景多样性。
